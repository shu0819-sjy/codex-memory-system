# 记忆写入规范

> 本文件是固定规范。自动化只读取它，不自动改写；修改规则前应由用户明确确认。

## 写入模板

- 格式：`- YYYY-MM-DD｜事实＋边界/检查`（单条 ≤3 行）
- 主题事实只写入对应 `spaces\*.md`；跨任务流程教训写入 `MEMORY.md` 的错误模式。
- 禁止机械追加、过程流水账、重复存放和编造事实。
- 不确定归属时只写入热层一行“待归类”，禁止猜分类。

## 写入安全

- 写入记忆文件先写同目录 `.tmp`，再使用原子替换。
- `MEMORY.md` 超过 10KB、分类文件超过 4KB时，先归档最旧条目。
- 归档文件统一命名为 `ARCHIVE\YYYY-MM-主题.md`。

## 官方记忆边界

- 文件系统是本模板的记忆载体；不要把个人记忆写入插件目录、项目源码或密钥文件。
